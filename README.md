Descripción del programa:

Este programa fue desarrollado en lenguaje C++ utilizando Programación Orientada a Objetos (POO).

Permite registrar la información de cinco libros ingresados por el usuario y posteriormente mostrar todos los datos almacenados.

Cada libro contiene la siguiente información:

1. Título
2. Autor
3. Año de publicación
4. Edición
5. Cantidad de páginas

La información es almacenada mediante una clase llamada Libro, utilizando atributos privados y métodos públicos.

Datos de entrada:

El usuario introduce mediante el teclado:

1. Título del libro.
2. Autor.
3. Año de publicación.
4. Edición.
5. Cantidad de páginas.
   
Datos que procesa:

El programa almacena la información de cinco libros utilizando un arreglo de objetos y organiza los datos para posteriormente mostrarlos en pantalla.

Datos de salida:

El programa muestra:

1. Título
2. Autor
3. Año de publicación
4. Edición
5. Cantidad de páginas

de cada uno de los cinco libros registrados.

Importancia de la encapsulación en POO:

La encapsulación es uno de los principios fundamentales de la Programación Orientada a Objetos. Consiste en proteger los datos de una clase evitando que sean modificados directamente desde otras partes del programa. Además, ayuda a mantener el programa más organizado, seguro y fácil de entender.

Cómo compilar y ejecutar el programa:

1. Abrir el proyecto en Visual Studio.
2. Presionar Ctrl + F5 o hacer clic en Local Windows Debugger para compilar y ejecutar el programa.
3. Ingresar la información de los cinco libros solicitados.
4. El programa mostrará en pantalla los datos registrados.
